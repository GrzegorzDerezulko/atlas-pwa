ETAP P — opcjonalna synchronizacja historii czatu

Dodaj poniższą regułę WEWNĄTRZ istniejącego bloku match /databases/{database}/documents { ... }.
Nie zastępuj działających reguł daily i activities.

match /users/{userId}/aiChats/{chatId} {
  allow read, write: if request.auth != null && request.auth.uid == userId;
}

Po opublikowaniu reguły włącz w ATLAS: Trener AI → Synchronizuj historię czatu przez Firebase.
Jeżeli nie dodasz tej reguły, czat AI nadal działa, ale historia pozostaje tylko na bieżącym urządzeniu.
