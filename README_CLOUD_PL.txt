ATLAS Cloud 1.0 – uruchomienie

1. W Firebase Authentication włącz Email/Password.
2. Zainstaluj dołączony ATLAS Sync Android 2.4 Account Bridge.
3. W Androidzie wpisz nowy e-mail i hasło, a następnie wybierz Połącz konto. To zachowuje aktualny anonimowy UID i istniejące dane Firestore.
4. Wgraj pliki PWA do GitHub Pages.
5. W PWA otwórz Zegarek / ATLAS Cloud i zaloguj się tym samym e-mailem oraz hasłem.
6. Dashboard zacznie słuchać zmian Firestore bez importu JSON.

Nie twórz konta najpierw w PWA. Konto należy najpierw połączyć w Androidzie, aby zachować obecny UID i dane.
