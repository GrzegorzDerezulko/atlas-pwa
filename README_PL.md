# ATLAS Sync Android v0.9

1. Uruchom synchronizację z Health Connect.
2. Po pojawieniu się danych kliknij **Wyślij dane do ATLAS PWA**.
3. Telefon otworzy adres ATLAS PWA.
4. PWA automatycznie zapisze dane na tym urządzeniu i pokaże komunikat o imporcie.

Synchronizowane są: kroki, aktywne kalorie, sen, tętno i dzisiejsze aktywności. Dane nie trafiają na zewnętrzny serwer - są przekazywane bezpośrednio między aplikacjami na telefonie.
